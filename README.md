# To-Do List

Простое консольное приложение для управления списком задач, написанное на Go.
Проект находится в разработке и подходит для изучения базовых возможностей языка: структур, срезов, функций, обработки пользовательского ввода и работы с консолью.

## Возможности

- добавление новых задач;
- просмотр списка задач;
- отметка задачи как выполненной;
- удаление задач;
- обработка некорректных номеров задач и неизвестных пунктов меню.

Задачи хранятся только во время работы приложения. После завершения программы список очищается.

## Требования

- Go версии 1.26.5 или новее;
- терминал с поддержкой стандартного ввода и вывода.

## Установка и запуск

Клонируйте репозиторий и перейдите в его директорию:

```bash
git clone https://github.com/arccthecoder/todo-list.git
cd todo-list
```

Запустите приложение:

```bash
go run .
```

Также можно собрать исполняемый файл:

```bash
go build -o todo-list .
./todo-list
```

## Использование

После запуска выберите действие в меню:

1. **Добавить задачу** — введите текст новой задачи.
2. **Показать задачи** — просмотрите все задачи и их статус.
3. **Выполнить задачу** — укажите номер задачи, которую нужно отметить выполненной.
4. **Удалить задачу** — укажите номер задачи для удаления.
5. **Выйти** — завершите работу приложения.
